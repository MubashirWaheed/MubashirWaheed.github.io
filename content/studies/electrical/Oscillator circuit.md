What is the composition of the Oscillator ciruit? 

There are four main elemenst to the oscillator circuit. 
1. Amplifier 
	It provides the energy lost in each cycle. For amplifier we can use op-amp, transistor or a switching negative-resistance
	device eg UJT/PUT 

2. Frequency determining network 
	This helps us decide which frequcny does the circuit runs on. It can be LC tank, RC network or quartz crystals for very 
	precise and stable frequencies 

3. Feedback path 
	Routes part of the output back to the input in phase. Im sine oscillators this is dedicated feedback network while in 
relaxation oscillators the switching device provides the regenrative action 

4. Dc power soruce 
	The oscillator converts the DC into AC output waveform
